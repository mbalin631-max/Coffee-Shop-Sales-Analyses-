# Coffee-Shop-Sales-Analyses-
An exploratory sales analysis of coffee shop transactions from January to June, using SQL, Excel and Power BI to examine revenue, product performance, store performance and sales patterns.

Coffee Shop Sales Analysis 
1. Overview
This project focuses on analysing coffee shop transaction data covering January to June. The objective is to explore sales performance, identify patterns in customer activity, and understand how different stores and products contribute to revenue.
The analysis examines key business metrics, including total revenue, units sold, transaction activity, product performance, and sales trends across different days and times.

2. Process
The project followed these steps:
Data Exploration: Examined the dataset structure, columns, and transaction information to understand the available data.
Data Quality Checks: Investigated duplicate transaction IDs, missing values, and unusual transaction quantities.
Data Preparation: Used SQL to organise the data, calculate key metrics, and classify sales by time of day and day type.
Data Analysis: Analysed revenue trends, store performance, product categories, and customer activity across different days and hours.
Data Visualisation: Developed dashboards and charts using Microsoft Excel, Power BI, Data Studio, Databricks, and Lovable to explore and present sales performance.
Recommendations: Identified areas for further investigation and developed potential recommendations based on the analysis.

3. Summary
This project provided an opportunity to apply data analytics techniques to a practical business scenario. By analysing coffee shop transaction data, I explored sales trends, revenue distribution, product performance, and customer activity.
The dashboards present the findings visually, making it easier to compare performance across stores, products, and time periods.
Through this project, I strengthened my understanding of SQL, data preparation, data analysis, and dashboard development. It also allowed me to practise using different tools to transform raw data into meaningful business information.

4. Tools Used
SQL: Data exploration, preparation, aggregation, and analysis.
Databricks: Writing and executing SQL queries.
Microsoft Excel: Data analysis, pivot tables, charts, and dashboard development.
Microsoft Power BI: Data visualisation and dashboard development.
Data Studio: Dashboard creation and data visualisation.
Lovable: Dashboard development and data presentation.
GitHub: Project documentation and portfolio management.
